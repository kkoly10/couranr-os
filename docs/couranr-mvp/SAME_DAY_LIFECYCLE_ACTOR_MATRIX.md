# Same Day lifecycle and actor matrix

This is the execution map for direct Consumer Same Day. The named SQL commands and the decision registry remain the enforcement authority; this matrix does not grant a permission. `S` is the direct customer/sender and payer, `R` the recipient, `D` the assigned driver, and `O` Couranr Operations. A token is a scoped capability, not an account. A request review or Help message is evidence for Operations, never a payment or custody command.

Security invariants: recipient tracking never authorizes sender pickup, payer action, or financial cancellation; sender recovery never authorizes recipient attestation or drop-off PIN; Help tokens authorize only one-delivery messages/evidence and stage-derived review requests. Drivers report facts, while Operations owns cancellation/return decisions. Automatic Consumer assignment is not production-verified by the current Operations-assigned canary.
